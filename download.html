No binary? No problem

Build it yourself.

Kepler compiles from a clean checkout on a stock toolchain. The release you'd have downloaded is byte-identical to what you get here.

  • Rust 1.78+, a C++ toolchain, and about 11 minutes.
  • --reproduce pins the toolchain and strips build paths.
  • Compare your digest against the published manifest.
# clone and build a release binary git clone https://example.invalid/kepler.git cd kepler cargo build --release --locked --features reproduce # serve this website + the release manifest cargo run -p kepler-releases -- --serve 8080 --root ./site # confirm you got the same bytes we did sha256sum target/release/kepler

# Kepler homepage

The site's `index.html`: a full-screen video hero built with React 19, Vite,
`motion` (Framer Motion) and `lucide-react`, styled with plain CSS.

```bash
npm install
npm run dev        # local dev server
```

To publish a change, run `npm run build`, then copy `dist/index.html` to the
site root as `index.html` and the files in `dist/assets/home/` into the site's
`assets/home/` folder (delete the old hashed files there first).

The previous homepage lives on as `classic.html`.

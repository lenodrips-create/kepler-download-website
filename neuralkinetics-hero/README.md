# NeuralKinetics hero

Full-screen hero landing page: React 19, Vite, `motion` (Framer Motion) and
`lucide-react`, styled with plain CSS and Inter from Google Fonts.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

A built copy is published with the Kepler site at `/hero/`
(rebuild it with `npx vite build --outDir ../hero --emptyOutDir`).
